## Problem

`biblio wiki lint docs/wiki/concepts/` (or any folder) prints `0 errors, 0 warnings` without checking any page. A false green: an agent following the skill ("lint <changed pages>") can pass a folder and believe the pages are clean.

## Evidence

With an invalid page in `docs/wiki/sources/` (see R10):

```
biblio wiki lint docs/wiki/sources/
0 errors, 0 warnings, 0 suggestions, 0 notes
biblio wiki lint docs/wiki/sources/alemanzapata-2026-deltas-spindles.md
     1  error      FM001    invalid YAML ...
1 errors, ...
biblio wiki lint
10 pages: 1 errors, ...
```

Expected: a folder expands to its pages; a path that matches no page is an error ("no pages matched").

## Request

Expand directory arguments recursively; exit non-zero (or at least warn) when the arguments match no page; print the page count for path runs as for full runs.

## How journal-club will use it

Lint after each ingest on the folders it touched.
