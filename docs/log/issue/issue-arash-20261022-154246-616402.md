**Current run:** the 2026-10-23 lab meeting on `alemanzapata_2026_DeltasSpindles` (Aleman-Zapata et al., *SLEEP* 2026, "Deltas' and spindles' cross-area synchronization and ripple subtypes"). Tracking: journal-club `backlogs/2026-10-23-alemanzapata-tooling.md` → section "Requests filed".

## Problem

In a projio workspace the config lives at `.projio/biblio/biblio.yml`, and `config.py:21` / `paths.py:11-21` know that. But `biblio docling run` and `docling batch` hardcode the legacy `bib/config/biblio.yml` when `--config` is not given, so they don't find the project's config.

## Evidence

- `cli.py:923` and `cli.py:995` build the legacy path instead of calling `default_config_path`.
- The `--config` help strings on every subcommand still say `bib/config/biblio.yml` (e.g. `cli.py:132`).
- Hit while running docling for `alemanzapata_2026_DeltasSpindles` in journal-club; it worked only with `--config .projio/biblio/biblio.yml`.

## Request

- Use `default_config_path` everywhere a subcommand resolves its config.
- Update the help strings.
- A test that `docling run` in a workspace with only `.projio/biblio/biblio.yml` picks it up.

## How journal-club will use it

journal-club drops `--config` from its recipes (README, CLAUDE.md) and from the skills it writes later.
