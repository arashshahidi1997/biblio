## Problem

`biblio wiki stub ... --title "A: b"` writes `title: A: b` without quotes. YAML rejects it, and the page fails lint with FM001. Source pages get titles like "Author et al. 2026: topic" naturally.

## Evidence

```
biblio wiki stub alemanzapata-2026-deltas-spindles --type source --title "Aleman-Zapata et al. 2026: ripple subtypes and delta-spindle coupling" --author llm --status draft
biblio wiki lint docs/wiki/sources/alemanzapata-2026-deltas-spindles.md
     1  error      FM001    invalid YAML: mapping values are not allowed here  [P7]
```

`biblio wiki status` then lists the page under type `?` and in neither the stub nor the draft column.

Expected: a valid page. Fix in journal-club: quoted the title by hand.

## Request

Write frontmatter with a YAML dumper (or quote strings that need it) in `scaffold.py`'s page template; the same for `aliases` and tags.

## How journal-club will use it

Every source page.

journal-club run backlog, request R10 (T12).
