## Problem

1. `--page` is resolved relative to the current directory, not the wiki. From the repo root, `--page concepts/x.md` (the form the skill and how-to suggest) prints a wrong relative path (`../bib/...` instead of `../../../bib/...`). Lint catches it as LNK004 afterwards, but only as a warning.
2. The snippet inlines the whole docling caption: for Fig 1 about 400 words with statistics. One embed pushed a concept page over the 800-word limit (SUG001). The caption keeps docling's ligature splits ("f iltered", "def lection") and garbles ranges: "pre-ripple (12040 ms before ripple)" for 120-40 ms, a number nobody should copy into a wiki.

After pasting the snippet into `concepts/ripple-subtypes.md`: `SUG001 908 words (limit 800)`. journal-club shortened the captions by hand to the figure title.

Expected: `--page` relative to the wiki root (or accept both and resolve the real file); a caption that fits a page.

## Request

- Resolve `--page` against the wiki root when the path exists there; error if the page doesn't exist.
- `--caption title|first-sentence|full` (default: title plus "(full caption in the paper)"); leave the long caption in the source page or the manifest.
- Don't count the embedded caption toward the word limit, or exclude figure blocks.
- Clean ligature splits in manifest captions; flag captions with digit runs that look like lost dashes.

## How journal-club will use it

Figure embeds on concept and source pages, and the same figures in the talk deck.
