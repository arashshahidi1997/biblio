## Problem

A quote checker for any markdown file, with one line numbering. Today's work (sourcing the room's 16 questions, adding 14 papers from Zotero) did this step one paper at a time or with a scratch script.

## Evidence

  - the T47 agent checked 109 quotes with a scratch script, `/storage2/arash/scratch/jc-spindle/check_quotes.py`, which imports `biblio.wiki.fidelity.QuoteChecker`;

## Request
 `biblio quotes check <file.md>` (name up to you):
  - reads the format journal-club uses in its source files: `- <id>, <citekey>, <section>, L<n>: "<quote>" — exact`;
  - looks the citekey up in the project and in the pools;
  - per quote reports exact / approximate (with the differing words) / not found, plus the line and the pool;
  - exits non-zero on anything not exact; writes JSON;
  - optional: rewrites wrong `L<n>` in place.
- **Line numbers:** the line the checker reports and the line `biblio fulltext --grep` prints should be the same number, defined once (the line in `<key>.md`).

**Done when:** `open-questions-sources.md` and `spindle-replay-sources.md` check in one call each, with the same lines as `fulltext --grep`.

## How journal-club will use it

The last check before a source file or slide is committed: no number or claim on a slide without a quote that checks exact.
